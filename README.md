# 🤖 Telegram-бот для магазина предзаказов

## Быстрый старт

### 1. Установите зависимости
```
py -3 -m pip install -r requirements.txt
```

### 2. Настройте config.py
Откройте `config.py` и замените:
- `ADMIN_ID` — ваш Telegram ID (узнать у @userinfobot)
- Контакт в функции `contact()` в файле `bot.py`

### 3. Запустите бота
```
py -3 bot.py
```

---

## Функции бота

### Для покупателей 🛍
- `/start` — главное меню
- Каталог товаров с фото
- Оформление предзаказа (размер, количество, адрес)
- Просмотр своих заказов и статусов

### Для администратора 👑
- `/admin` — открыть панель администратора
- Добавление товаров (с фото)
- Просмотр всех заказов
- Изменение статуса: `/setstatus <id> <статус>`
- Удаление товара: `/delproduct <id>`

### Статусы заказа
| Код | Значение |
|-----|----------|
| `new` | 🆕 Новый |
| `paid` | 💳 Оплачен |
| `shipped` | 🚚 Отправлен |
| `delivered` | ✅ Доставлен |
| `cancelled` | ❌ Отменён |

При смене статуса клиент получает автоматическое уведомление.
